Resumen del Design System

Este prototipo demuestra la implementación de un Design System desarrollado exclusivamente con HTML5 y CSS3. Se utilizaron variables CSS, componentes reutilizables, modelo de cajas (box-sizing), tarjetas (Cards), botones, formularios, tablas, badges, alertas, efectos hover, focus, animaciones y diseño responsive, estableciendo una línea gráfica consistente para el Sistema de Gestión de Incidentes (Help Desk).
